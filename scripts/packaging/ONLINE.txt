REREVVED ONLINE

Online play for ReRevved. One player's PC runs the online server, which passes
game traffic between everyone. Everyone must run the identical release.

HOSTING

1. Set up your game content as in README.txt.
2. Start ReRevved, press F1 for Settings, select Online, and press Host Game.
   The game closes and starts again as the host: it runs the online server
   itself and asks your router to open UDP port 30100.
3. Allow rerevved.exe through the Windows Firewall prompt.
4. Open F1 > Online and read Hosting Status. When it says friends can join,
   they click Join on your Discord profile, or you send them an invite from
   a Discord chat (the + button, then Invite to Play). See JOINING. No code
   is needed.
5. For friends without Discord, press Copy Friends' Code and send them the
   code privately.
6. When done, press Stop Hosting, which replaces Host Game while you host, or
   quit the game. Either one stops the online
   server and removes the router port.

The online server allows up to eight members. While you host, ReRevved ignores
your saved Invite Code and Direct LAN and plays on its own server; the saved
settings stay unchanged.

The password behind your invite codes is server-password.txt, in:
  userdata\online-server, in the game folder
An existing password is reused, never overwritten, so your friends' code stays
the same until the address changes. The script below uses the same file.

For another UDP port, start the game once from a Command Prompt in the package
folder, then press Host Game:
  rerevved.exe --online_host_port=30200

Hosting Status reads:
Not hosting: Press Host Game.
Starting: asking your router for a port: Wait a few seconds.
Hosting. Friends join from your Discord profile or invite: Create a Player
  Match game with an open slot; friends then join from Discord.
Hosting. Press Copy Friends' Code and send it: Join Button or Online Player
  Match is off, so friends need the code.
Can't host: <reason>: See CAN'T HOST?. After fixing it, press Stop
  Hosting and then Host Game to try again.

HOSTING WITH THE SCRIPT

Use this when the button cannot host (see CAN'T HOST?) or the game is not on
Windows.

1. Close ReRevved, then double-click host-online.cmd. It tries to open UDP
   port 30100 with router UPnP, then NAT-PMP, makes invites, copies the
   friends' code to the clipboard, starts the online server, and launches
   ReRevved connected to it.
2. Allow rexglue.exe through the Windows Firewall prompt.
3. Let friends use Discord Join (see JOINING), or send them the copied code
   privately.
4. Keep the script window open while playing. Press Ctrl+C there when done.
   Check the port mapping was removed; remove it in your router if it remains.

The script also stores invite-codes.txt and online-server.log (the online
server's log) in userdata\online-server.

For another UDP port, run: host-online.cmd -Port 30200

If ReRevved was already running, close it and run the script again.
The script tries to remove mappings it added or reclaimed. Closing its window
can leave a mapping open. A stale mapping it repoints stays for a later run to
reclaim. Check your router after testing even if hosting worked.
A NAT-PMP mapping lasts one hour, is renewed while the script runs, and
expires by itself if the window is closed.

JOINING

Discord Join is recommended. Use the Discord desktop app, not the browser.
1. Start the game once with Join Button on (the default) to register with
   Discord.
2. Close ReRevved, then click Join on the host's Discord profile while they
   host a Player Match game with an open slot.

Discord starts the game on the host's online server. Your saved Invite Code
and Direct LAN settings are kept but unused for that launch.

To use a code instead:
1. Start the game, press F1 for Settings, and select Online.
2. Paste the complete RXR1-... code into Invite Code. Click outside the field
   or press Enter to apply it. Keep Direct LAN off when using an invite.
3. Select Save at the bottom, exit the game, and start it again.
4. Check Connection Status in F1 > Online. After a few seconds it should read
   "Online: connected as 198.18.x.y".

Optional settings: Profile Name, in F1 > General, accepts 1-15 characters:
letters, digits, spaces, hyphens, underscores, or periods. Empty gives
Player-XXXX online.
Direct Connection lets two players who enable it try a direct connection
with each other, and use the online server if that fails. The game creates
and saves a random player ID automatically on the first online launch.

If ReRevved is running when you click Discord Join, it joins in place on the
same online server with Online Player Match on. Otherwise, it explains why and
asks you to close the game and click Join again.

PLAYING

Open Multiplayer > Player Match. Online Player Match is on by default.
Everyone must use invite codes from the same host. One player hosts
with an open public slot; the others see it in the game list with the host's
name and ping, and join.
The host's gameplay settings apply to everyone, and Settings shows them locked
once you join. A player whose mods differ from the host's can't ready up: enable
the same mods in F2, restart, and join again.
Ranked Match finds no games.
The host must stay until the game ends. The game can't pass hosting to another
player, so if the host leaves, everyone has to quit. Stop Hosting, quitting
the host's game, or closing the host's script window disconnects everyone.

CAN'T HOST?

Host Game asks your router for the port itself and works on any
Windows network profile. When it cannot host, the usual causes are: router
UPnP is off, CGNAT (your provider shares one Internet address between
customers), or another NAT layer. Hosting Status names the cause it found.

The script asks through Windows instead. When that fails, it names the
cause and asks for an address friends can reach. Host Game avoids the
first two causes.

"Windows treats this network as Public": Windows hides the router from the
script on a Public network, which is common on Wi-Fi. The script opens the
Settings page; switch to Private there and host again:
  Settings > Network & internet > Ethernet or Wi-Fi >
  Network profile type > Private network

"The Windows service "SSDP Discovery" is disabled": open the Services app,
double-click SSDP Discovery, set Startup type to Manual, and host again.

"Your router did not answer": turn on UPnP or NAT-PMP in the router's
settings; either one is enough. Some shared networks, such as dorms and
hotels, offer neither.

"Your router is behind another router or your Internet provider's shared
address": common on mobile, satellite and apartment Internet. No router
setting fixes it; use one of the options below.

"Windows Firewall blocks rexglue.exe": the firewall prompt was closed or
denied earlier, and Windows does not ask again. Open "Allow an app through
Windows Firewall", tick rexglue.exe for your network type, and host again.

"A VPN (its name) carries this PC's Internet traffic": friends reach your router, but
the replies leave through the VPN. Turn the VPN off while hosting.

If another program already uses the port on your router, the script moves to
the next free one of ten and says which.

A friend hosts: someone whose PC can host automatically presses Host Game,
and everyone else joins.

Overlay VPN: everyone installs a VPN such as Tailscale or ZeroTier and joins
the same network. The host closes ReRevved, runs host-online.cmd and enters
their overlay address when asked, such as the 100.x.y.z address Tailscale shows.

A different outside port: if friends must connect on a port other than the
one the script uses, add it after the address when asked, such as
example.net:41234. The online server on this PC keeps its own port, and the
friends' code and Discord Join carry the one you typed.

UDP tunnel, not tested by the project: a tunnel service gives the host a
public address and port and passes UDP traffic to this PC, so friends install
nothing. Point the tunnel at UDP 30100 on this PC, run host-online.cmd, and
enter the tunnel's address and port when asked. The service must carry UDP;
a TCP or HTTP tunnel does not work. Your game traffic passes through the
service unencrypted (see SECURITY LIMITS).

Manual port forward, for advanced users: forward UDP 30100 (or your chosen
port) in your router to this PC's local IPv4 address. Run host-manual.cmd and
enter your public IPv4 or DNS name when asked. It makes codes and runs the
online server. Start the game yourself with the this-PC code (see JOINING).
Use copied codes: this script does not set the public advertised address for
Discord Join. Remove the rule after testing.

Discord Join needs an address friends can reach. Hosting from the game uses
the address your router reports. The automatic script sets the advertised
address when the full address and port fit the SDK's 35-character limit.
Otherwise, it tells friends to use the copied code.

TWO COPIES ON ONE PC

Start the first copy normally. From a Command Prompt in the package folder,
start the second with a separate storage profile:
  rerevved.exe --profile=second
Use this argument every time. Set up its content and Online settings
separately, with a different player name. Its config and automatically saved
player ID are separate; do not copy the first profile's config. On the PC
running the script's online server, use the this-PC code from
invite-codes.txt. See
README.txt for profile details.

WHAT TO REPORT

Report exact Status text, approximate time, what you tried, what happened,
package version, and whether you hosted or joined.
F1 > General > Open Log Folder opens game logs. The second copy's
logs are in userdata\profiles\second\logs. Script hosts can also provide
online-server.log from userdata\online-server. Never share
server-password.txt or invite codes publicly.
Check screenshots and attachments for codes before sharing.

TROUBLESHOOTING

Off: Paste the invite, click outside the field, Save, and restart.
LAN: Turn Direct LAN off before using an invite, Save, and restart.
Online: waiting for System Link: The game has not started networking yet; wait
  a few seconds after the intro.
Online: connecting: Wait briefly, then check the host is still hosting.
Online: connected as 198.18.x.y: The connection to the online server is ready.
  If the game list is empty, check for a Player Match host with an open slot
  on the same host's online server and Online Player Match on for both players.
(Online Player Match unavailable): Online Player Match needs an invite and
  Direct LAN off.
Online: lost connection: Check the host is still hosting and both Internet
  connections. Restart the game once the online server is reachable.
Online: disconnected: The game closed its online connection normally.

For "Online failed: <reason>":
not an invite code: Copy the complete code again without labels or extra text.
invite code is damaged or incomplete: Copy the complete code again.
invite code was made for a newer version: Everyone must run the identical
  package.
turn off Direct LAN to use an invite code: Turn Direct LAN off, Save, and
  restart.
server address not found; check your network: Ask the host to check the
  DNS name and make a new code if needed. Check your Internet connection.
the host's online server is not responding: Check the host is still hosting
  and the port is open (see CAN'T HOST?). With the script, the host's PC uses
  the this-PC code.
invite code does not match this server: Ask the host for the current code
  (Copy Friends' Code, or invite-codes.txt with the script).
different game build: Everyone must unzip and run the same download.
different ReRevved version: Everyone must unzip and run the same download.
the game is full: Close extra game copies and wait for their connections to
  expire before retrying. The online server allows eight members.
the online server has too many games open: Ask the host to finish unused test
  games, then retry with the group's current code.
too many attempts; wait and try again: Stop repeated connection attempts, wait
  briefly, and retry. If it continues, report the time and relevant logs in
  Discord. Remove invite codes first: https://discord.gg/j6VttvdnMD
invite expired; ask for a new invite: The Discord join expired. Close the game
  and click Join again while the host's game is still hosted.

After changing an invite or other Online setting, Save and restart. Only Rich
Presence applies without a restart.

SECURITY LIMITS

Invite codes contain the password for your game. Treat them like passwords;
share only with players joining your game. Game traffic through the online
server is not encrypted and is not protected against tampering. Run the
online server only for the private game and close the port afterwards.
