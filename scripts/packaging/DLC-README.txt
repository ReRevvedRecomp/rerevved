RETAIL DLC

Put your own Xbox 360 DLC package files for the game in this folder, then
restart ReRevved. ReRevved ships no DLC; use only content you own.

On the console drive, the packages are the files with 42-character names in:

  Content\0000000000000000\545407E5\00000002\

Copy each file as it is. Do not rename, unpack or edit it. ReRevved reads the
packages in place and never writes to them or to this folder.

Keep one package per pack. When two packages provide the same pack, scenario
file or scenario ID, the first by file name is used and the other is refused.
Refused files are listed in the log with the reason.

Elemental multiplayer maps need the same DLC on every player's computer.
